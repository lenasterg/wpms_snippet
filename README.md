##LSDC – Dashboard Post Counts
lsdc-dashboard-post-counts.php file

A lightweight WordPress Must-Use (MU) plugin that extends the Dashboard's At a Glance section with additional post and page statistics.

###Features
1. Displays Draft, Pending, and Scheduled counts for Posts and Pages.
2. Provides direct links to filtered content management lists.
3. Respects user permissions using native WordPress capabilities.
4. Supports WordPress native labels, statuses, and translations.
5. Hides content statuses with zero entries.
6. Follows WordPress security and output escaping best practices.

###Technical Details
Developed in PHP using native WordPress hooks and functions.
No external libraries, APIs, or database modifications.
No additional configuration required.
Installation

Place the lsdc-dashboard-post-counts.php file in:
/wp-content/mu-plugins/
The plugin loads automatically as a Must-Use plugin.
